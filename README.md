# 令和8年（2026年）熊本地震 調査報告

**公開版**: https://dobachi.github.io/kumamoto-earthquake-2026-report/

2026年7月28日16時27分に発生した令和8年熊本地震（M7.1、最大震度7）の調査記録。

## この記録の方針

- **事実には出典の原文をそのまま併記する。** 引用は出典ページを再取得して実在を機械照合する
- **推論は `【推】` を冠して事実と区別する**
- **探して見つからなかったことも記録する**

本文では三区分を見た目でも分けている（`reports/kumamoto-2026/evidence.lua`）。

| 区分 | 意味 |
|---|---|
| 出典 | 出典が実際に書いていること |
| 未照合 | 出典ページを取得できず、実在を確認できていない引用 |
| 推論 | 筆者の読み |

## ビルド

```bash
make html      # docs/ へ出力
make preview   # ローカルプレビュー
make check     # 三区分が変換されているか確認
```

`make check` は必ず通すこと。**Quarto は Lua フィルタが効かなくてもビルドを成功させる**ため、
区分が落ちても気づけない。

## 数値について

**すべて速報値であり、確定値ではない。** 被害の数字はまだ動いている
（全壊は 8/9 → 8/11 の2日で 62% 増）。本記録は消防庁 第49報（2026年8月11日16時00分）時点。
